# National Park Academy — Вэб сайт

Монгол Улсын Тусгай хамгаалалттай газруудын менежментийг сайжруулах, олон улсын сайн туршлагыг нэвтрүүлэх **National Park Academy (NPA)** хөтөлбөрийн албан ёсны вэб сайт.

«NPA Web Requirement Doc (2024.11.16)» баримтын шаардлагын дагуу бүтээв.

## Технологи

| Хэсэг | Технологи |
|---|---|
| Backend | Laravel 13 (PHP 8.4), session-д суурилсан auth |
| Frontend | Vue 3 SPA (Vue Router, Pinia), Vite |
| Загвар | Tailwind CSS v4 |
| Өгөгдлийн сан | SQLite (MySQL/PostgreSQL руу .env-ээс шилжүүлж болно) |

## Суулгах заавар

```bash
# 1. Хамаарлууд
composer install
npm install

# 2. Орчны тохиргоо
cp .env.example .env
php artisan key:generate

# 3. Өгөгдлийн сан (SQLite) + жишээ өгөгдөл
touch database/database.sqlite
php artisan migrate --seed

# 4. Файл хадгалалтын холбоос
php artisan storage:link

# 5. Frontend build
npm run build

# 6. Ажиллуулах
php artisan serve
# → http://127.0.0.1:8000
```

Хөгжүүлэлтийн үед `npm run dev`-ийг `php artisan serve`-тэй зэрэг ажиллуулна (hot reload).

## Үндсэн боломжууд

### Нийтийн хэсэг
- **Нүүр** — hero, тоон үзүүлэлт, хөтөлбөрүүд, удахгүй болох арга хэмжээ, ТХГ, мэдээ
- **Бидний тухай** — зорилго, танилцуулга, он цагийн хэлхээс, хамт олон (бүрэн намтартай)
- **Хөтөлбөрүүд (8)** — NPA паспорт, Хуралдай, Өсвөрийн байгаль хамгаалагч, Бүсийн сургалт, Эгч дүүс парк, Сайн дурын ажил, Дадлага, Нээлттэй ажлын байр
- **ТХГ-ууд** — аймаг/төрөл/нэрээр хайлт, дэлгэрэнгүй мэдээлэл (амьтад, газарзүй, хүрэх зам г.м), Google Maps линк, ХЗ-ны харьяа ТХГ-ууд
- **Сайн дурын ажил** — аймаг, ТХГ, хугацаагаар ХЗ хайх + хүсэлт илгээх (popup баталгаажуулалттай)
- **Мэдээ** — дотоод болон гадаад линктэй (gogo.mn г.м) 2 төрөл
- **Тусламж** — FAQ + санал хүсэлт (төрөл/дэд сэдэв сонголттой)
- **Хэл** — Монгол / Англи (UI бүрэн, MN контент үндсэн)
- **NPA туслах** — FAQ дээр суурилсан чат туслах (баруун доод буланд)

### Бүртгэл, нэвтрэлт
- Зөвхөн ТХГ-ын ажилтнууд бүртгүүлнэ; овог нэр **кириллээр** (шалгалттай), утас/и-мэйл формат шалгана, давхар бүртгэлд «Уучлаарай, Та бүртгэлтэй байна.»
- Бүртгэл админ баталгаажуулсны дараа идэвхжинэ («ажлын 72 цагийн дотор»)
- Нууц үг мартсан → админд хүсэлт очно, супер админ түр нууц үг үүсгэнэ

### Хэрэглэгчийн dashboard
- Профайл (нас автоматаар, хүйсийн icon, зураг оруулах), мэдээлэл засах (нууц үгээр баталгаажна)
- **NPA тамга** — өөрийн ХЗ-ны тамга жил жилээр, нийт/энэ жилийн тоо, тамга бүрийн дэлгэрэнгүй (хэзээ, яагаад, хэн), жилд 50 хүртэл
- **Сургалт** — YouTube/PDF/зураг, албан тушаал + бүсээр шүүгдэнэ
- Удахгүй болох арга хэмжээ + Бүртгүүлэх товч, миний бүртгэлүүд

### Арга хэмжээний бүртгэл (асуулга)
- Товч огноогоор автоматаар идэвхжинэ: «Бүртгэл эхлээгүй байна» / «Бүртгэл дууссан байна» / нээлттэй / «Тун удахгүй...»
- Нэвтрэлт шаардах/шаардахгүй горим; асуултын төрлүүд: Тийм/Үгүй, текст (үгийн хязгаартай), линк, зураг (4MB), нэг сонголт, олон сонголт
- Дутуу бөглөвөл илгээгдэхгүй; бүртгэл CMS-д харагдана

### Админ панел (CMS) — `/admin`
- **Хэрэглэгчид** — баталгаажуулах/татгалзах/засах/устгах, нууц үг сэргээх, эрхийн зохицуулалт (супер админ)
- **NPA тамга** — ХЗ-д тамга нэмэх/засах/хасах (шалтгаан + админы лог), жил бүрийн тохиргоо (эхлэх/дуусах огноо, загвар зураг), ХЗ-ээр нэгтгэсэн тоо
- **Сургалт, арга хэмжээ** — асуулга бүтээгч (хэдэн ч асуулт), огноо нээх/хаах, бүртгэлүүд харах
- **Санал хүсэлт** — шүүх, дэлгэрэнгүй, хариу өгсөн/өгөөгүй статус; сайн дурын хүсэлтүүд
- **Мэдээ / Ажлын байр / ТХГ / ХЗ / FAQ / Сургалтын материал** — бүрэн CRUD
- **Тохиргоо** — цэс нуух/харуулах, санал хүсэлтийн төрөл нэмэх/хасах, админы жагсаалт
- **Мэдэгдэл** — шинэ бүртгэл, хүсэлт бүр админ панелд + и-мэйл логт бүртгэгдэнэ

## И-мэйл илгээлт

SMTP тохируулаагүй үед бүх и-мэйл `mail_outbox` хүснэгтэд хадгалагдаж, админ панелын «И-мэйл лог» хэсэгт харагдана. Бодит илгээлт хийхийн тулд `.env`-д:

```
MAIL_MAILER=smtp
MAIL_HOST=...
MAIL_PORT=587
MAIL_USERNAME=...
MAIL_PASSWORD=...
MAIL_FROM_ADDRESS=info@mongolec.org
```

## Зураг солих

`public/images/` доторх бүх зураг нь placeholder SVG. Бодит зургуудаа мөн нэрээр нь (өргөтгөл нь өөр байж болно — DB/CMS-ээс зам солино) тавьж солино:

- `hero.svg` — нүүрний том зураг
- `park-*.svg` — ТХГ-ын зургууд (CMS-ээс ТХГ бүрд өөр зураг оруулж болно)
- `news-*.svg`, `gallery-*.svg` — мэдээ, галерей
- `stamp-YYYY.svg` — жил бүрийн тамганы загвар (админ панелаас солино)
- `passport.svg`, `yosemite.svg`, `denali.svg`, `logo.svg`
